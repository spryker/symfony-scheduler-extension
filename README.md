# SymfonySchedulerExtension Module
[![Latest Stable Version](https://poser.pugx.org/spryker/symfony-scheduler-extension/v/stable.svg)](https://packagist.org/packages/spryker/symfony-scheduler-extension)
[![Minimum PHP Version](https://img.shields.io/badge/php-%3E%3D%208.3-8892BF.svg)](https://php.net/)

This module provides plugin interfaces for SymfonyScheduler module.

## Installation

```
composer require spryker/symfony-scheduler-extension
```

## Usage

### SchedulerHandlerProviderPluginInterface

This plugin interface allows you to provide scheduled message handlers and their schedules to the SymfonyScheduler module.
